# Accessory role matching

Version 0.10.4 adds role-aware catalogue aliases for application accessories.

The roller role can discover products named as roller sleeves through terms including `sleeve`, `microfibre`, `microfiber` and `pile`. Brush and tray roles also receive role-specific search vocabulary.

A sleeve is allowed as a partial roller-role recommendation only when the live product data identifies it as a sleeve. The response must state that a compatible roller frame is still required and must never present the sleeve as a complete roller.
