# Complete kit planning

Version 0.10.2 keeps complete-kit requests comprehensive without allowing missing accessories to suppress a verified primary material.

When a customer asks for everything needed, a complete kit or all materials, the semantic router should include relevant preparation and application roles such as primer, filler, roller, brush and tray. The principal material remains required; supporting roles remain optional unless the customer specifically asks for one of them as the primary product.

Missing optional roles are reported to the answer stage but do not trigger a manager handoff when a confirmed principal material is available.
